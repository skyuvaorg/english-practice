# English Practice

A personal English learning app built with Next.js. Contains ~1000 Tamil-English sentence pairs extracted from 5 PDF books.

## Features

- **5 Books** with Tamil sentences and hidden English translations
- **Reveal/Hide** English for individual cards or all at once
- **Search** across Tamil and English sentences
- **Learned tracking** with localStorage persistence
- **Filter** by All / Not learned / Learned
- **Dark theme** with proper Tamil font support (Noto Sans Tamil)
- **Responsive** grid layout for mobile and desktop

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

Push to GitHub and import the repo on [vercel.com](https://vercel.com).
